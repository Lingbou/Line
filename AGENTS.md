## Agent skills

### Issue tracker

Issues, specs, and tickets are tracked in GitHub Issues for `Lingbou/Line` using `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

The default canonical labels are `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with a root `CONTEXT.md` and decisions under `docs/adr/`. See `docs/agents/domain.md`.
